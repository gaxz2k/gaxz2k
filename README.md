# Nicholas Alhambra

Desenvolvedor Backend Pleno, especialista em integrações de sistemas em ambientes SaaS. Atuo principalmente com Ruby on Rails, AWS (SQS, S3, IAM), APIs REST, mensageria e bancos de dados relacionais, transformando fluxos de integração complexos em soluções confiáveis, escaláveis e observáveis.

## Áreas de atuação

- Desenvolvimento e manutenção de integrações via APIs REST
- Processamento assíncrono e mensageria com Amazon SQS (filas FIFO)
- Armazenamento e manipulação de arquivos com Amazon S3
- Gestão de acessos e permissões com AWS IAM
- Investigação de incidentes, análise de logs e troubleshooting em produção
- Testes automatizados e melhoria contínua da confiabilidade das entregas
